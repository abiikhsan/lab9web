## Tujuan Project
Mempelajari modularisasi program PHP,
penggunaan function, template, dan routing.

## Perangkat
- XAMPP
- Visual Studio Code
- PHP
- MySQL

## Cara Menjalankan
1. Simpan folder Lab9Web di htdocs.
2. Jalankan Apache melalui XAMPP.
3. Buka browser.
4. Masukkan localhost/Lab9Web/

## Struktur Project
- config: konfigurasi database
- views: halaman tampilan
- helpers: kumpulan function
- modules: modul pengguna
- assets: file CSS dan JavaScript

## Daftar Routing
- home
- profil
- kontak
- dashboard
- user/list
- user/add
- user/edit
- user/delete
